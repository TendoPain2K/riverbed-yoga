TOUCHSTONE 3 - RIVERBEND YOGA STUDIO

This continues the four HTML pages from Touchstone Task 2.
All four now link to styles.css. No JavaScript or extra dependencies.

SETUP
1. Extract the ZIP. Upload the four HTML files and styles.css to the same
   folder in your existing GitHub project, replacing the Task 2 versions.
2. Keep the media folder beside those files. Add the original Sophia files:
   yoga-studio_c.png, yoga-instructor_c.png, yoga-workshop_c.png,
   yoga-feature-small_c.png, yoga-feature-large_c.png,
   yoga-breathing_c.mp3.
   Screenshots of filenames are not the actual images or audio.
3. Preview your project using your course's Codespaces instructions.
   A simple option is python3 -m http.server 8000 from the project folder.
   Open the Ports tab, then open port 8000 in the browser.
4. Commit your changes to your existing GitHub repository. Confirm the
   repository is public and that someone else can open the link.
5. Copy the repository URL into Section 1 of the Word document.
   Copy your working preview URL into the second space. Test both links.
   A Codespaces preview may depend on the Codespace remaining running;
   confirm the course's required sharing method before submitting.
6. Review the pages at phone and desktop widths and test the navigation,
   images, audio, and form using sample information.
7. Copy the design explanation into Sophia's original template if needed.
   The supplied Word file recreates the sections shown in your screenshots.
8. Submit the completed template with your actual links. The ZIP contains
   your project files; the assignment asks for one completed template file.

DESIGN
Colors: cream #FAF7EF, forest green #31564A, sage #DEE8DB,
charcoal #24302A. Fonts: Georgia headings and Arial body text.
Flexbox is used for navigation, page sections, class cards, and the form.
At 800px and wider, the header becomes a row, class cards become three
columns, and most page sections become two columns.

Section 4 needs one screenshot from your actual website preview.
Take a screenshot of the Services page at desktop width to show the
three class cards beside each other, then insert it into Section 4.
The original media files still must be added before full media testing.
The form is a demonstration: browser validation works, but the form does
not send or store a studio request. Use sample information to test it.
